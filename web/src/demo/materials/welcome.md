# Welcome to ClassPort

Explore a sample semester without signing in.

- Browse courses, schedules, exams, and study topics.
- Complete a task, add your own, or edit a course.
- Preview sample files and search their contents.
- Choose any of the seven themes in Settings.
- Open the MCP example to replay a preset study workflow.

Changes are saved only in this browser. Use Reset demo to restore the initial semester.

The MCP example is a simulation with prepared responses. Cloud uploads, account security, and external integrations are available in the full self-hosted application.
